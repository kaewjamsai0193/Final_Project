# ระบบจัดการอู่ซ่อมรถ

เว็บแอปจัดการอู่ซ่อมรถสาขาเดียว ใช้ได้ทั้งคอมและมือถือในวงแลนของอู่
ดูแลสินค้าและสต็อก (คิดต้นทุนเฉลี่ยให้เอง) ใบสั่งซื้อ การรับของเข้าคลัง และบัญชีผู้ใช้ 3 บทบาท

## สถานะ

| เฟส | เรื่อง | สถานะ |
|---|---|---|
| 0–1 | ติดตั้ง ฐานระบบ ล็อกอิน | เสร็จ |
| 2 | ผู้ใช้ ค่าตั้งอู่ | เสร็จ |
| 3 | สินค้า สต็อก ต้นทุนเฉลี่ย | เสร็จ |
| 4 | ใบสั่งซื้อ รับของเข้าคลัง | เสร็จ |
| 5–9 | ใบงานซ่อม บิลและรับเงิน ประวัติรถ เตือนบำรุงรักษา หน้าแรกและรายงานภาษี | กำลังทำ |

## ทำอะไรได้แล้ว

- **ล็อกอิน** ด้วยชื่อผู้ใช้และรหัสผ่าน รหัสเก็บแบบเข้ารหัส (Argon2) ระบบจำสิทธิ์จาก token (JWT)
- **ผู้ใช้** เจ้าของอู่เพิ่ม แก้ ปิดบัญชี และตั้งรหัสผ่านใหม่ให้พนักงานได้ ไม่มีการลบบัญชี
- **ค่าตั้งอู่** ชื่ออู่ ที่อยู่ เลขผู้เสียภาษี อัตรา VAT
- **สินค้าและสต็อก** เพิ่มและแก้สินค้า ลงสต็อกตั้งต้น แจ้งของเสียหรือของหาย (ต้องใส่เหตุผล) และดูสมุดสต็อกที่จดทุกครั้งที่ของเข้าออก
- **ต้นทุนเฉลี่ย** ระบบคิดใหม่ทุกครั้งที่ของเข้า `(คงเหลือ × ต้นทุนเดิม + มูลค่าที่เข้า) ÷ (คงเหลือ + จำนวนที่เข้า)`
- **ใบสั่งซื้อ (PO)** เจ้าของอู่ออกใบ พิมพ์ส่งร้าน และปิดใบก่อนรับครบได้ถ้าใส่เหตุผล
- **รับของ** ทยอยรับตามใบสั่งซื้อได้หลายรอบ ระบบไม่ยอมให้รับเกินยอดสั่ง และปิดใบสั่งซื้อให้เองเมื่อรับครบ

## เริ่มใช้งาน

1. คัดลอกไฟล์ตั้งค่า

   ```
   cp .env.example .env
   ```

2. แก้ `.env` กรอก 4 ช่องนี้ (ถ้าเว้นว่างหรือใช้ค่าตัวอย่าง ระบบจะไม่ยอมเริ่ม)
   - `JWT_SECRET` ข้อความสุ่มยาว ๆ
   - `ADMIN_USERNAME` ชื่อผู้ใช้ของเจ้าของอู่
   - `ADMIN_PASSWORD` รหัสผ่านเจ้าของอู่ อย่างน้อย 6 ตัว
   - `ADMIN_EMAIL` อีเมลเจ้าของอู่ ไว้รีเซ็ตรหัสผ่านตอนลืม

   ส่งเมลรีเซ็ตรหัสผ่าน (ไม่กรอกก็เปิดระบบได้ ลิงก์จะไปโผล่ใน `docker compose logs api` แทน)
   - `SMTP_HOST` `SMTP_PORT` `SMTP_USER` `SMTP_PASSWORD` เช่น Gmail ใช้ `smtp.gmail.com` พอร์ต 587 รหัสเป็น App Password
   - `APP_URL` ที่อยู่เว็บที่ใส่ในลิงก์ ใช้ IP เครื่องนี้ถ้าจะกดจากมือถือ เช่น `http://192.168.1.10:5173`
   - แก้ `.env` แล้วต้อง `docker compose up -d` ใหม่ api ถึงจะเห็นค่าใหม่

3. เปิดระบบ

   ```
   docker compose up --build
   ```

4. เปิดใช้งาน
   - หน้าเว็บ http://localhost:5173 (มือถือในวงแลนเดียวกันใช้ `http://<IP เครื่องนี้>:5173`)
   - เอกสาร API http://localhost:8000/docs

บัญชีเจ้าของอู่สร้างจาก `.env` ให้ครั้งแรกที่เปิดระบบ ตารางในฐานข้อมูลสร้างและอัปเดตเองทุกครั้งที่ api เริ่ม

## คำสั่งที่ใช้บ่อย

```
docker compose exec api python -m pytest -q        # รันเทสต์
docker compose exec api ruff check .               # ตรวจโค้ด Python
docker compose exec api ruff format .              # จัดรูปแบบโค้ด Python
docker compose exec web npm run format             # จัดรูปแบบโค้ดหน้าเว็บ
docker compose exec api alembic revision --autogenerate -m "ชื่อ"   # สร้าง migration หลังแก้ models.py
docker compose exec db psql -U garage -d garage    # เข้าฐานข้อมูล
```

## ลืมรหัสผ่าน

- คนที่มีอีเมลในระบบ: หน้าเข้าสู่ระบบ → ลืมรหัสผ่าน? → กรอกชื่อผู้ใช้ → กดลิงก์ในอีเมล (ใช้ได้ครั้งเดียวภายใน 30 นาที)
- คนที่ไม่มีอีเมล: เจ้าของอู่ไปที่ ตั้งค่า → ผู้ใช้ → แก้ไข → เปลี่ยนรหัสผ่าน
- เจ้าของอู่ต้องมีอีเมลเสมอ (ระบบไม่ให้บันทึกถ้าไม่มี) ถ้าส่งเมลไม่ได้ ให้คนที่เข้าเครื่องเซิร์ฟเวอร์ได้รันคำสั่งนี้ (แก้ `owner` เป็นชื่อผู้ใช้จริง และ `newpass123` เป็นรหัสใหม่)

  ```
  docker compose exec api python -c "from sqlalchemy import select; from app.db import SessionLocal; from app.models import User; from app.auth import password_hash; db=SessionLocal(); u=db.scalar(select(User).where(User.username=='owner')); u.password_hash=password_hash.hash('newpass123'); db.commit()"
  ```
